# SWYNEX-Exploratory-Data-Analysis

## Retail Sales Data Analysis using Microsoft Excel

This project was completed as part of the **SWYNEX Data Analyst Internship – Task 2**. The objective of this task was to analyze a retail sales dataset using Microsoft Excel and generate meaningful insights through data analysis and visualization.

## Project Objective

The main objective of this analysis is to understand sales performance across different product categories, regions, and order quantities.

## Tools Used

- Microsoft Excel
- Data Analysis
- Charts & Data Visualization
- Excel Worksheets

## Analysis Performed

The following areas were analyzed:

1. **Revenue by Product Category**
   - Smartphones generated the highest revenue of **₹93,81,056**.
   - Laptops generated **₹92,75,846**.
   - Smartwatches generated the lowest revenue of **₹42,91,542**.

2. **Orders by Region**
   - The dataset contains **8,010 orders** across the North, South, East, and West regions.
   - Regional order distribution was analyzed to understand differences in customer activity.

3. **Quantity Sold by Product Category**
   - The total order quantity across all transactions is **40,033 units**.
   - Product categories were compared based on their quantity sold.

4. **Unit Price by Order Quantity**
   - The aggregated unit-price value across all order-quantity levels is **₹64,23,368**.
   - The **5-unit order quantity level** recorded the highest aggregated value of **₹9,16,776**.

5. **Overall Sales Performance**
   - Total Orders: **8,010**
   - Total Revenue: **₹3,20,67,213**
   - Total Order Quantity: **40,033 units**

## Key Insights

- Smartphones were the highest revenue-generating product category.
- Laptops also contributed significantly to total revenue.
- Smartwatches recorded the lowest revenue among the analyzed categories.
- Customer order activity varied across different regions.
- Smartphones and Laptops represented a significant share of the total quantity sold.
- The 5-unit order quantity level recorded the highest aggregated unit-price value.
